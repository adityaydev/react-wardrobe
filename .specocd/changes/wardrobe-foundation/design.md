# Architecture

React Aria supplies keyboard/focus behavior; scoped CSS tokens supply appearance. Theme context is explicitly applied to portalled overlays. React and React DOM remain peers; React Aria, date utilities and icons remain external runtime dependencies. CSS is a separate documented import. The showcase composes the package without clinic API coupling.

See DESIGN_PRINCIPLES.md and README.md for interaction rules, notification transport boundaries, privacy considerations, theming and component recipes.
